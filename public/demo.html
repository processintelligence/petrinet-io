petrinet-io - Demo for BPM 2026

petrinet-io is a web-based Petri net modeling and simulation tool built on top of diagram-js. This library allows you to create, edit, simulate, and export Petri nets using an intuitive visual interface.

This demo

This demo shows a deployment of petrinet-io in a larger context.

At the top there are tabs that can be used to model several Petri nets at the same time, while maintaining each environment isolated from the other.

Library Installation

Use the library by installing it via npm into your application using: npm install petrinet-io.

Library Usage

To get started, just include the library and call the construction, providing the element that should contain the editor:

import { PetriNetIO } from "petrinet-io";

const pn = new PetriNetIO({
	container: "#canvas",
});
